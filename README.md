# Skillpath — Framer Assignment

A responsive learning platform landing page built in Framer.

## Features

- Dynamic course data from API
- Country-based INR/USD pricing
- Loading, error and empty states
- Retry functionality
- Course search
- Responsive 3/2/1 column layout
- Framer property controls
- Refundable course badges

## API

Course data:
https://syncsphere-hiv6.onrender.com/assignment/course-data

Country:
